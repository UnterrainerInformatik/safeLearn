# Combined markers and closed entries

A directive never shows a block to more readers than its author wrote: view markers combine with AND, written roles that are all closed are not replaced by the markers beside them, and an entry whose window cannot be read is closed for good.

## The teacher-only revealable solution

@@@ #variant-private, #optional
COMBINED-SOLUTION: shown to a teacher with the variant and the optional view on.
@@@

## Both variants

@@@ #variant-private, #variant-public
BOTH-VARIANTS: shown to nobody.
@@@

## A class window that closed long ago

@@@ 4bhif[2020-01-01T08:00:00 to 2020-01-31T18:00:00], #optional
CLOSED-CLASS-WINDOW: shown to nobody, whatever the optional view.
@@@

## One role still open

@@@ teacher, 4bhif[to 2020-01-31T18:00:00], #optional
OPEN-TEACHER-ROLE: shown to a teacher with the optional view on.
@@@

## A window that cannot be read

@@@ teacher[morgen], #optional
UNREADABLE-WINDOW: shown to nobody.
@@@
