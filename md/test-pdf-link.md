# PDF links

The fixture page of `test/checks/pdf-embeds.js` for wiki links to an attachment that is not a Markdown page. The PDF's name holds a space and an umlaut, so the link has to address it percent-encoded.

## By name

[[test-pdf mündlich.pdf]]

## With its own text

[[test-pdf mündlich.pdf|Arbeitsblatt]]

## In code

Written as an example of the syntax, so it stays as written: `[[test-pdf mündlich.pdf]]`
