# Where these files came from

Seven of the eight bolds here are byte-identical copies of the file beside them
in `assets/main-fonts/`, as the regulars already are; see that directory's
`SOURCES.md` for the release each came from — including why
`OpenDyslexic3-Regular-700` is an `.otf` where every other file here is a `.ttf`.

`PT Sans Narrow` is the one typeface this directory has to itself, and the one
download made for the navigation alone.

| typeface | version | release |
| --- | --- | --- |
| PT Sans Narrow | 2.003W | Google Fonts, `fonts.google.com/download/list?family=PT+Sans+Narrow` |

The licence of a shared family is duplicated here rather than left one directory
over. The two directories are served independently and a font travels with the
terms it is licensed under, so a directory holding fonts and no licences is the
thing to avoid — the duplication is four kilobytes and the alternative is a gap.

Nothing under `.nav-font` sets `font-style: italic`, so this directory carries
bolds and no italics. If an italic is ever wanted here, the filename convention
already covers it.
